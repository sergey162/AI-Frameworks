## Датасеты

| Задача | Данные | Цель | Основная метрика |
|---|---|---|---|
| Классификация | [Loan Approval Classification Data, Kaggle](https://www.kaggle.com/datasets/taweilo/loan-approval-classification-data) | Статус заявки `loan_status` | F1 класса 1 |
| Регрессия | [Concrete Compressive Strength, UCI №165](https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength) | Прочность бетона `strength`, МПа | MAE, МПа |

Датасеты выбраны с учётом требования уникальности среди участников группы. Проверка по [таблице группы](https://docs.google.com/spreadsheets/d/1szg1vYr3MLq8eqCejGbvVOdF7t87slb3h2x8qv2e-So/edit?gid=0) не выявила совпадений с выбором других студентов.

Классификация решает задачу предварительного прогноза статуса заявки. Регрессия оценивает прочность по составу смеси и возрасту образца — исходную задачу UCI. Для бетона разделение и CV выполняются по рецептурам: измерения одной смеси в разном возрасте не пересекают train/test и фолды. Источники, лицензия UCI, словарь и SHA256 файлов: [data/README.md](lab_1/data/README.md).

## Запуск

Python 3.12; команды из корня репозитория:

```bash
python3 -m venv lab_1/.venv
source lab_1/.venv/bin/activate
python -m pip install -r lab_1/requirements.txt
python lab_1/download_data.py
python lab_1/run_notebooks.py
```

Оба исходных файла включены в репозиторий: шаг загрузки проверяет SHA256, а скачивает только при отсутствии корректного файла. Ноутбуки сохранены с результатами, для просмотра на GitHub вычисления не нужны. Полное повторное выполнение включает CV на всех обучающих объектах и полный поиск соседей, поэтому может занять несколько минут.

Интерактивная работа:

```bash
source lab_1/.venv/bin/activate
python -m jupyterlab
```

Для интерактивной работы используется Python из `lab_1/.venv`. Скрипт `run_notebooks.py` сам запускает Jupyter-ядро тем интерпретатором, которым вызван, и последовательно выполняет исследование и общее сравнение.

Проверки собственной реализации:

```bash
cd lab_1
.venv/bin/python -m pytest -q
```

Окружение `.venv` исключено из Git; версии библиотек зафиксированы в `lab_1/requirements.txt`.
