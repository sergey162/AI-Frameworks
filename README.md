В репозитории собраны исследования алгоритмов для классификации и регрессии.
В каждой работе я сравниваю исходные и улучшенные модели sklearn со своей реализацией.
Основной ход исследования, графики и выводы находятся в Jupyter Notebook.

Ноутбуки сохранены с результатами, поэтому их можно просмотреть прямо на GitHub.

## Данные

Для классификации использую [Loan Approval](https://www.kaggle.com/datasets/taweilo/loan-approval-classification-data):
по сведениям о клиенте нужно предсказать одобрение кредитной заявки.
Основная метрика — F1 класса 1.

Для регрессии использую [Concrete Compressive Strength](https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength):
по составу и возрасту бетона нужно предсказать прочность в МПа.
Основная метрика — MAE.

Во всех работах сохраняю одинаковые train/test. Для бетона разделение выполняю по рецептурам,
чтобы одна смесь в разном возрасте не попадала одновременно в обучение и проверку.
Описание признаков, источники и лицензия — в [описании данных](lab_1/data/README.md).

## Как запустить

Python 3.12, команды из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python lab_1/download_data.py
python run_notebooks.py
```

Скрипт выполнит четыре работы и обновит общее сравнение. Для одной работы:
`python run_notebooks.py --labs 4` (также доступны `--labs 1`, `--labs 2` и `--labs 3`).
Подойдёт и ранее созданное окружение `lab_1/.venv`.

Для интерактивного просмотра: `python -m jupyterlab`.
Проверка собственных реализаций: `python -m pytest -q`.

В папках `lab_1`, `lab_2`, `lab_3` и `lab_4` находятся notebook, исходный код и результаты экспериментов.
Данные хранятся в `lab_1/data` и используются всеми четырьмя работами.

В №4 дополнительно исследуются число деревьев, bootstrap, доля признаков, веса классов,
OOB, устойчивость к seed и важности признаков. Собственный лес на NumPy обучается на полном train.
В notebook показан весь код, результаты CV, диагностика ошибок и выводы по каждому этапу.
