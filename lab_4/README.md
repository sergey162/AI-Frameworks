# Лабораторная работа №4 — случайный лес

**[Открыть notebook с исследованием](random_forest_research.ipynb)**

В этой работе я исследую Random Forest для классификации кредитных заявок и прогноза
прочности бетона. Сохраняю данные, признаки, train/test и CV-фолды работ №1–3.
Для каждой задачи сравниваю исходный и улучшенный sklearn с исходной и улучшенной
собственной реализацией на NumPy. Все модели обучаются на полном train.

В notebook находятся пояснения к каждой ячейке кода, практическое обоснование задач,
формулы, полный код алгоритма, таблицы, графики и выводы по каждому этапу задания.
Результаты сохранены для просмотра на GitHub без запуска.

## Что исследуется

- Предобработка: scaling, log-преобразования, новые отношения признаков.
- Число деревьев, глубина, размер листа, случайный выбор признаков и веса классов на CV.
- Bootstrap, OOB-покрытие, качество и отличие OOB от групповой CV для бетона.
- Перенос выбранных улучшений в собственные леса без повторного подбора.
- Устойчивость к seed, ошибки, MDI и permutation importance на CV-validation.
- Парные bootstrap-интервалы разностей, сравнение качества и времени с №1–3.

Собственная реализация использует NumPy для bootstrap, CART, выбора признаков, вероятностей,
прогнозов и OOB. Готовые деревья/ансамбли sklearn не вызываются. Bootstrap материализован
повторяющимися строками: ограничения `min_samples_*` считают повторы; отличие от sklearn
и его влияние на сравнение подробно описаны в notebook.
