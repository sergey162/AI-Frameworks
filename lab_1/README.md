# Лабораторная работа №1 — KNN

**[Открыть notebook с исследованием](knn_research.ipynb)**

В работе я исследую метод k ближайших соседей на двух задачах:
одобрение кредитных заявок и прогноз прочности бетона.
Сравниваю исходные модели sklearn, варианты с улучшенной предобработкой
и свою реализацию на NumPy.

В notebook приведены выбор данных и метрик, анализ распределений, проверка гипотез,
подбор параметров, графики ошибок и итоговые выводы.
Каждой ячейке с кодом предшествует пояснение.
