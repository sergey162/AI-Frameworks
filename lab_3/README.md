# Лабораторная работа №3 — решающее дерево

**[Открыть notebook с исследованием](decision_tree_research.ipynb)**

В этой работе я исследую CART для классификации кредитных заявок и прогноза прочности бетона.
Использую данные, train/test и CV-фолды первых двух работ. Сравниваю исходные и улучшенные
деревья sklearn со своими реализациями на NumPy. Проверяю масштабирование,
логарифмирование, новые признаки, ограничение сложности и веса классов.

В notebook находятся комментарии к каждой ячейке кода, формулы, код алгоритмов,
результаты экспериментов, графики и выводы по всем этапам, включая сравнение с №1–2.
Таблицы и графики сохранены для просмотра на GitHub.

## Запуск

Из корня репозитория в общем окружении:

```bash
python run_notebooks.py --labs 3
python -m pytest -q
```
