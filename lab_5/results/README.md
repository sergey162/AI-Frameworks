# Сохранённые результаты лабораторной №5

Файлы формируются при полном выполнении [ноутбука](../gradient_boosting_research.ipynb).
`metrics.csv` совместим с отдельной сводкой `comparison.ipynb`.

| Файл | Содержание |
|:--|:--|
| `metrics.csv` | Все test-метрики, время полного Pipeline, SHA данных и разбиений |
| `protocol.json`, `selected.json` | Протокол, пространство поиска и выбранные настройки |
| `split_*.csv`, `cv_folds.csv` | Исходные row_id, train/test, группы и CV-фолды |
| `predictions_*.csv` | Истина, прогнозы и вероятности на test для каждой модели |
| `hypotheses.json`, `hypothesis_summary.csv` | Изолированные проверки предобработки и разности CV-score |
| `leaf_cv.json` | Изолированная проверка минимума объектов в листе |
| `trajectory_*.csv` | Train/CV-score и потери каждой траектории, стадии и фолда |
| `cv_classification.csv`, `cv_regression.csv` | Все кандидаты, оценки фолдов, среднее и разброс |
| `complexity.csv`, `agreement.json` | Сложность, train-качество и расхождения реализаций |
| `subsample_audit.csv` | Фактический размер и уникальность подвыборок собственных моделей |
| `train_loss.csv` | История потерь на полном train собственных моделей |
| `seed_cv.json` | CV-оценки выбранного sklearn по трём seed |
| `permutation_importances.csv` | Важности исходных признаков на validation первого CV-фолда |
| `paired_bootstrap.csv` | Разности test-метрик и условные 95% percentile-интервалы |
| `cross_lab_bootstrap.csv` | Прямое сравнение улучшенных sklearn №5 и №4, формируется итоговым notebook |

CV-score — F1 / **отрицательная MAE**: больше — лучше. В `metrics.csv` MAE обычная,
положительная. Train-loss — log-loss для классификации и MSE для регрессии;
это функции обучения, отличающиеся от основных критериев отбора.

`trajectory_fit_seconds` относится к обучению всей траектории из 200 деревьев на уже
подготовленных данных фолда; это не время обучения конкретной стадии. В `metrics.csv`
время включает полный Pipeline и не включает CV-поиск. Все времена — один запуск.

`feature_set` перечисляет исходные входы для контроля сопоставимости работ;
`representation` / `mode` задают их преобразования и новые признаки. В бутстрепе
классификации ресэмплируются строки, регрессии — целые test-рецептуры. Интервалы условны
относительно фиксированных обученных моделей и не учитывают подбор гиперпараметров.
Важности на CV-validation описательные: фолд уже участвовал в выборе настроек.
