# Лабораторная работа №5 — градиентный бустинг

**[Открыть notebook с исследованием](gradient_boosting_research.ipynb)**

В этой работе я исследую градиентный бустинг для исторического одобрения кредитных заявок
и прогноза прочности бетона. Сохраняю данные, исходные входы, train/test, CV-фолды и метрики
работ №1–4. Для обеих задач сравниваю исходный и улучшенный sklearn с исходной и улучшенной
собственной реализацией. Все итоговые модели обучаются на полном train.

Notebook содержит пояснения к каждой ячейке кода, обоснование задач и метрик, формулы,
полный код, таблицы, графики и численные выводы по каждому обязательному этапу.
Сохранённые результаты доступны на GitHub без запуска Python.

## Что исследуется

- Исходные GradientBoostingClassifier / Regressor и Dummy.
- Scaling, log-преобразования, новые отношения признаков и размер листа.
- Совместный выбор learning_rate, числа деревьев, глубины, подвыборки и представления.
- 17 траекторий по 200 деревьев на задачу, три CV-фолда, оценки на 25/50/100/200 итерациях.
- Собственные градиенты, Newton-значения листьев, shrinkage и подвыборки без возвращения.
- Ручная проверка одного шага и перенос улучшений без повторного подбора.
- Кривые train/CV, потери, ошибки, важности, устойчивость к seed и парные интервалы.
- Сравнение всех пяти алгоритмов на общем holdout.

Основные метрики: F1 для классификации и MAE в МПа для регрессии. Дополнительно считаются
precision, recall, accuracy, balanced accuracy, ROC-AUC, AP, RMSE и R².
Обучение минимизирует log-loss / квадрат ошибки; отбор выполняется по F1 / MAE.
Классификация использует фиксированный порог 0,5. Для бетона GroupKFold исключает
пересечение рецептур; внутренняя случайная validation sklearn отключена.

Собственный бустинг использует NumPy и [собственное CART из №3](../lab_3/src/decision_tree.py).
Готовые деревья и ансамбли sklearn не вызываются. Поддерживаются бинарная классификация
и одноцелевая регрессия. Разрешение равноценных порогов, численная арифметика и генератор
подвыборок могут давать расхождения со sklearn; фактические расхождения показаны в notebook.
