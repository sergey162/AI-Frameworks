# Лабораторная работа №2 — логистическая и линейная регрессия

**[Открыть notebook с исследованием](linear_research.ipynb)**

В этой работе я использую те же данные и разбиения, что и в первой лабораторной.
Для классификации обучаю логистическую регрессию, для прогноза прочности бетона — линейную.
Проверяю логарифмирование, дополнительные признаки, полиномы и регуляризацию,
затем переношу выбранные улучшения в собственные реализации на NumPy.

В notebook находятся пояснения, формулы, исходный код алгоритмов,
таблицы качества, графики и сравнение с KNN.
